# MedCardy | پلتفرم هوشمند فلش‌کارت پزشکی (پروتوتایپ UI/UX)

پروتوتایپ تعاملی طراحی رابط و تجربه کاربری (UI/UX) وب‌سایت **MedCardy** با تکنولوژی Vanilla HTML5, CSS3, JavaScript و فونت استاندارد وزیرمتن (Vazirmatn).

## 🌟 ویژگی‌ها و امکانات پروتوتایپ

### ۱. پالت رنگی و استایل بصری:
- **تم آبی پزشکی ملایم (Light Medical Blue):** پس‌زمینه‌های گرادینت آسمانی به همراه گوی‌های نورانی متحرک (`Ambient Glowing Orbs`).
- **کارت‌ها و پنل‌های شیشه‌ای (Glassmorphism):** افکت شیشه‌ای با بلور نرم، حاشیه‌های براق کریستالی و سایه‌های ملایم.
- **انیمیشن‌های نرم و طبیعی:** ترنزیشن‌های نرم، انیمیشن شناور، لرزش آتشین استریک و چرخش ۳بعدی فلش‌کارت.

### ۲. سوئیچر تعاملی ۴ نوع چیدمان داشبورد (Dashboard Variants):
- **۱. کویزلت مدرن (Quizlet Modern):** کارت‌محور، مینیمال، ساختار منظم، نوار وضعیت جانبی و کارت‌های پیشرفت مباحث.
- **۲. دولینگو انگیزشی (Duolingo Pulse):** تمرکز بر زنجیره مطالعه (Streak آتشین 🔥)، نوار هدف روزانه XP، ماموریت‌های روزانه و دکمه سه‌بعدی تپنده.
- **۳. آنکی کامند سنتر (Anki Command Center):** ماتریس دیتامحور تفکیک کارت‌ها (جدید، یادگیری، سررسید، عقب‌افتاده)، هیت‌مپ فعالیت روزانه مشابه گیت‌هاب و پارامترهای FSRS.
- **۴. شیفت و کشیک (Clinical Shift):** مخصوص کشیک‌های بیمارستانی و اورژانس با دکمه‌های بزرگ و ارگونومیک (یک‌دستی) جهت مرورهای سریع ۵ تا ۱۰ دقیقه‌ای.

### ۳. سوئیچر ۳ سبک دکمه‌ها (Button Styles):
- **شیشه‌ای کریستال (Crystal Glass):** افکت بلور شیشه‌ای با انعکاس نور
- **سه‌بعدی گیمین (3D Tactile):** دکمه‌های برجسته با عمق فیزیکی مشابه دولینگو
- **خطی مینیمال (Clinical Outline):** طراحی خطی تخت و تمیز کلینیکال

### ۴. بخش‌های تعاملی پیاده‌سازی شده:
- **مرور فلش‌کارت (Study Room):** کارت ۳بعدی با قابلیت چرخش، سناریوی بالینی ECG و ۴ دکمه استاندارد FSRS (دوباره، سخت، خوب، راحت) به همراه پشتیبانی از کلیدهای کیبورد (Space و کلیدهای ۱ تا ۴).
- **حالت ریکاوری (Recovery Mode):** اسلایدر محاسبه زمان آزاد دانشجو و ارائه نسخه هوشمند جبران کارت‌های عقب‌افتاده.
- **کتابخانه دروس (Courses):** دسته‌بندی مباحث پزشکی (قلب، فارما، ریه، نورولوژی، ICU، جراحی).
- **نتیجه جلسه (Results):** خلاصه عملکرد، نرخ یادآوری، کاهش عقب‌افتادگی و انیمیشن موفقیت.

## 🚀 نحوه مشاهده و اجرا

### ۱. اجرای پروژه Next.js (فرانت‌اند جدید):
```bash
cd frontend
npm run dev
```
سپس مرورگر را باز کرده و به آدرس `http://localhost:3000` بروید.

### ۲. مشاهده پروتوتایپ قبلی (Test Frontend):
کافیست فایل [test-frontend/index.html](test-frontend/index.html) را مستقیماً در هر مرورگری باز کنید یا تست‌های آن را با دستور زیر اجرا کنید:
```bash
node test-frontend/tests/test-suite.js
```

### آپلود روی اکانت گیت‌هاب و فعال‌سازی آنلاین (GitHub Pages):
1. در گیت‌هاب یک ریپوزیتوری جدید با نام `MedCardy` بسازید.
2. دستورات زیر را در ترمینال اجرا کنید:
```bash
git add .
git commit -m "feat: Initial MedCardy UI/UX interactive prototype"
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/MedCardy.git
git push -u origin main
```
3. در صفحه ریپوزیتوری گیت‌هاب خود، به بخش **Settings > Pages** بروید.
4. بخش **Branch** را روی `main` و مسیر را روی `/ (root)` بگذارید و Save بزنید.
5. لینک زنده شما آماده خواهد شد (مثلاً: `https://<YOUR-USERNAME>.github.io/MedCardy/`).
